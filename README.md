## Aim

To create prompts using different prompt engineering techniques, namely Straightforward Prompting, Tabular Format Prompting, Preceding Question Prompting, and Missing Word Prompting, and evaluate the generated responses using a Unit 5 use case.

## Use Case: Artificial Intelligence in Education

Artificial Intelligence (AI) is used in education to provide personalized learning, automate assessments, answer student questions, and improve the teaching and learning process.

## Explanation

### 1. Straightforward Prompting

**Definition:** Straightforward prompting gives a clear and direct instruction to the AI system to obtain a specific response.

**Prompt:**

"Explain three benefits of Artificial Intelligence in education in simple English."

**Generated Output:**

1. **Personalized Learning:** AI provides learning materials based on individual student needs.
2. **Automated Assessment:** AI helps evaluate tests and assignments quickly.
3. **24/7 Learning Support:** AI-powered chatbots can answer students' questions at any time.

**Evaluation:** The prompt generated a direct, simple, and relevant response.

### 2. Tabular Format Prompting

**Definition:** Tabular format prompting instructs the AI system to present information in a table for easy understanding and comparison.

**Prompt:**

"Create a table showing four applications of Artificial Intelligence in education, their uses, and their benefits."

**Generated Output:**

| Application | Use | Benefit |
|---|---|---|
| AI Chatbots | Answer student questions | Instant support |
| Adaptive Learning | Personalize learning materials | Individual learning |
| Automated Grading | Evaluate objective tests | Saves time |
| Learning Analytics | Analyze student performance | Identifies learning gaps |

**Evaluation:** The table presents information in an organized format, making it easy to understand and compare.

### 3. Preceding Question Prompting

**Definition:** Preceding question prompting provides a question or context before the main instruction to guide the AI system toward a relevant answer.

**Prompt:**

"Why do students need personalized learning? Explain how Artificial Intelligence helps teachers identify student learning difficulties and provide suitable learning materials."

**Generated Output:**

Students have different learning speeds, abilities, and interests. Artificial Intelligence analyzes students' answers, learning progress, and performance to identify areas where they need help. It can recommend suitable lessons, exercises, and practice questions. Teachers can use this information to provide additional support and improve learning outcomes.

**Evaluation:** The preceding question gives context and helps generate a focused and meaningful explanation.

### 4. Missing Word Prompting

**Definition:** Missing word prompting provides an incomplete sentence or statement with a blank that the AI system must complete.

**Prompt:**

"Artificial Intelligence helps students learn by providing personalized ______, automating assessments, and answering questions."

**Generated Output:**

"Artificial Intelligence helps students learn by providing personalized **learning materials**, automating assessments, and answering questions."

**Evaluation:** The AI correctly completes the sentence with a suitable phrase related to the context.

## Comparison of Prompting Techniques

| Prompt Type | Main Purpose | Output |
|---|---|---|
| Straightforward | Obtain a direct answer | Simple explanation |
| Tabular Format | Organize information | Table |
| Preceding Question | Provide context | Detailed explanation |
| Missing Word | Complete an incomplete statement | Missing phrase |

## Result

Thus, the four prompt engineering techniques were executed successfully using the use case of Artificial Intelligence in Education. The generated outputs were evaluated based on relevance, clarity, organization, and correctness. Each technique was found useful for obtaining different types of responses from an AI system.

## Conclusion

Prompt engineering helps users communicate effectively with AI systems. Straightforward prompting produces direct answers, tabular format prompting organizes information, preceding question prompting provides context, and missing word prompting completes incomplete statements. Selecting a suitable prompting technique improves the quality and usefulness of AI-generated responses.
